# 🛡️ NetGuard
### Intelligent Public Wi-Fi Security Analysis and Threat Detection System

NetGuard is an Android-based Wi-Fi security analysis application developed using Flutter. It helps users inspect nearby Wi-Fi networks and understand their advertised security configurations before connecting.

## ✨ Features

- 📡 Scan nearby Wi-Fi networks.
- 🔍 Analyze Wi-Fi security configurations.
- 🔐 Identify open and weakly secured networks.
- 📶 Display network information such as SSID, signal strength and frequency.
- 🟢 Show security status using GOOD, WARNING and DANGER indicators.
- 📊 View Wi-Fi analysis history.
- 📚 Access Wi-Fi security awareness guides.
- ⚙️ Manage application settings.

## 🛠️ Technologies Used

- Flutter
- Dart
- Kotlin
- Android SDK
- Android Wi-Fi APIs

## 📱 Application Modules

1. **Home** – Main dashboard.
2. **Analyze** – Scan and inspect nearby Wi-Fi networks.
3. **History** – View previous analysis records.
4. **Guide** – Learn about Wi-Fi security.
5. **Settings** – Manage app preferences.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Android Studio or VS Code
- Android device or emulator

### Installation

Clone the repository:

```bash
git clone https://github.com/balajisriram24/NetGuard.git
```

Open the project:

```bash
cd NetGuard
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

## ⚠️ Important Note

NetGuard analyzes Wi-Fi scan information and the security capabilities advertised by nearby access points. Its current version does not guarantee detection of all network attacks or threats.

Wi-Fi scanning may require location permission and enabled location services on Android.
